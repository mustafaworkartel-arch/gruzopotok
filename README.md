# ГРУЗОПОТОК

Статический сайт ООО «ГРУЗОПОТОК» о дизельном топливе для бизнеса. Создан с применением Sites, публикация по запросу владельца — GitHub и Vercel.

## Локальный просмотр

`python3 -m http.server 4187 --directory dist`

Открыть http://localhost:4187.

## Публикация

Vercel: Framework Preset `Other`, Output Directory `dist`, без команды сборки. Конфигурация — `vercel.json`.
